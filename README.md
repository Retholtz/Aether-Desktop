Presently Alpha Build

Download Aether-Setup.exe
     - This will install all of the required files (Microsoft Edge Webview, Visual Code Distributable, ViGeMBus)
     - Installs Aether


Once installed please go to https://aistudio.google.com/api-keys to obtain an API key. Once API key is created and funded place the API key into settings and the program is ready to go.



***If Setup file is not working or if you want to just use the .zip archive the following files are needed for Aether to work***

Needed files:
Download Checklist for Your Installer (Prereqs\ Folder)
[ ] Microsoft Edge WebView2 Evergreen Bootstrapper

Where to get it: [Download the Evergreen Bootstrapper (~2 MB) from the Microsoft Edge WebView2 Developer page.](https://go.microsoft.com/fwlink/p/?LinkId=2124703)

[ ] Microsoft Visual C++ Redistributable (v14 / 2015–2022+, x64)

File to save: vc_redist.x64.exe

Where to get it: Direct Microsoft permalink: https://aka.ms/vc14/vc_redist.x64.exe (or from the Microsoft Visual C++ Redistributable documentation).

[ ] ViGEmBus Driver (v1.22.0)

File to save: ViGEmBus_1.22.0_x64_x86_arm64.exe

Where to get it: [Download the final release (v1.22.0) from the official nefarius/ViGEmBus GitHub Releases page.](https://github.com/nefarius/ViGEmBus/releases/download/v1.22.0/ViGEmBus_1.22.0_x64_x86_arm64.exe)
